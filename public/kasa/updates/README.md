# SalonGo Kasa — installers and auto-update feed

Static files served by the website (Vercel) at `https://salongo.eu/kasa/updates/...`.
Not touched by the i18n proxy (`src/proxy.ts` skips every path with a dot), so URLs are exact.

```
public/kasa/updates/
  mac/
    latest-mac.yml              ← electron-updater feed for macOS (generated by electron-builder)
    SalonGo-Kasa-<ver>-universal.dmg / .zip (+ .blockmap)   ← files named in latest-mac.yml
    SalonGo-Kasa-latest.dmg     ← copy of the newest .dmg (target of /kasa/download/mac)
  win/
    latest.yml                  ← electron-updater feed for Windows
    SalonGo-Kasa-Setup-<ver>.exe (+ .blockmap)              ← file named in latest.yml
    SalonGo-Kasa-latest.exe     ← copy of the newest .exe (target of /kasa/download/win)
```

- In the Kasa app, the generic publish provider points at `https://salongo.eu/kasa/updates/mac` and
  `https://salongo.eu/kasa/updates/win`.
- Short download links (redirect 302, `next.config.mjs` → `KASA_INSTALLER`):
  `/kasa/download/mac` → `/kasa/updates/mac/SalonGo-Kasa-latest.dmg`,
  `/kasa/download/win` → `/kasa/updates/win/SalonGo-Kasa-latest.exe`.
  The page `/<locale>/kasa/download` links to these.
- Headers (`next.config.mjs`): `*.yml` → `text/yaml`, `*.dmg` → `application/x-apple-diskimage`,
  `*.exe` → `application/vnd.microsoft.portable-executable` (both `Content-Disposition: attachment`);
  everything here `Cache-Control: max-age=0, must-revalidate` (the feed must never be stale) and `X-Robots-Tag: noindex`.
- Upload order for a release: installers + blockmaps first, then the `latest*.yml`, then the `SalonGo-Kasa-latest.*` copies.
- `public/kasa/config.json` (signed remote config) is NOT kept in this repo: the Kasa app repo's tooling produces and
  signs it and places it at `public/kasa/config.json` (served as `https://salongo.eu/kasa/config.json`).
- Size: installers are large binaries; if the repo or Vercel deployment size becomes a problem, move this folder to
  object storage / GitHub Releases and keep only the redirects here.
