# Ảnh cho trang Tính năng

Copy 5 file ảnh vào **public/images/** hoặc **public/images/features/**.

| Tên file (đặt đúng) | Block trên web |
|---------------------|----------------|
| `../lich-hen-nhan-vien.webp`, `../lich-hen-danh-sach.webp` | Lịch hẹn thông minh (2 chế độ xem) |
| `../tinh-tien.webp` | Thanh toán nhanh chóng (màn Tính tiền) |
| `../tong-quan.webp`, `../doanh-thu.webp`, `../hoa-don.webp` | Báo cáo: Tổng quan, Doanh thu, Hoá đơn |
| `../lich-hen-online.webp` | Lịch hẹn online (danh sách chờ duyệt + popup thông báo) |
| `trang-nhan-vien.jpg` | Tài khoản riêng cho nhân viên |

- Định dạng: **.jpg** (hoặc đổi code sang .png nếu bạn dùng PNG).
- Nếu ảnh của bạn đang ở ngoài project (Desktop, thư mục features khác): copy vào đây và đổi tên cho đúng bảng trên.
| `../khach-hang.webp` | Khách hàng & tích điểm |
| `../dich-vu.webp` | Dịch vụ & bảng giá |
| `../tinh-luong.webp` | Tính lương tự động |
