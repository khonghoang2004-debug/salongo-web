# Ảnh cho trang Tính năng

Ảnh màn hình app nằm trong **public/images/**, rộng 2400px (đã bỏ thanh menu bên trái của app).
Danh sách tính năng và ảnh dùng cho từng phần nằm ở `src/components/featuresData.ts`.

| Tên file | Phần trên trang |
|----------|-----------------|
| `../dat-lich-khach.webp`, `../lich-hen-online.webp` | Đặt lịch online: trang của khách, duyệt trong app |
| `../lich-hen-nhan-vien.webp`, `../lich-hen-danh-sach.webp` | Lịch hẹn: theo nhân viên, danh sách |
| `../tinh-tien.webp` | Tính tiền |
| `../khach-hang.webp` | Khách hàng & tích điểm |
| `../dich-vu.webp` | Dịch vụ & bảng giá |
| `../tong-quan.webp`, `../doanh-thu.webp`, `../hoa-don.webp` | Báo cáo: tổng quan, doanh thu, hoá đơn |
| `../tinh-luong.webp` | Tính lương |

Tài khoản nhân viên không dùng ảnh: phần minh hoạ được vẽ bằng giao diện trong `src/components/StaffAccountVisual.tsx`.
